03 Shorthand

plain text → <t s="Default">…</>
[Whisper]hi[/] → <t s="Whisper">hi</>
[Spell*]hi[/] → <t s="Spell" donthide>hi</>
@WaveHand → <anim n="WaveHand"></>
@WaveHand! → <anim n="WaveHand" ovlook="true"></>
@- → <stopanim></>
%RaiseBrow=0.8 → <m t="RaiseBrow">0.8</>
[img:Star] → <img id="Star"></>
[w:Choice] → <w id="Choice"></>
{pc} → <pc/>
(a thought) → passes through as-is
\@ \[ \% \{ \\ → escape → literal char

Spans nest: [A]x[B]y[/]z[/] closes inner first. Event tags sit between text runs, matching the doc's examples.

Output uses the short tag forms (<t>, <anim>, <m>, <img>, <w>) — identical in behaviour to the long forms in your spec.
